# Landscape and scope

Multi-agent deliberation systems increasingly preserve independent first-round answers, and some warn about same-lab correlation. EchoQuorum is deliberately narrower: it is not a debate framework. It is a drop-in verifier that asks whether a claimed *quorum* contains enough independently-originating provenance groups to deserve that name.

Adjacent references reviewed during design:
- Quorum deliberation projects on GitHub that preserve independent rounds.
- Agent governance systems that score individual or cumulative action risk.
- Agent identity/provenance standards emerging across the ecosystem.

EchoQuorum composes with those systems; it does not replace them.
